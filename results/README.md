# Results

This directory contains evaluated test-set metrics generated by `evaluate.py`.

## Files

| File | Description |
|---|---|
| `test_metrics.json` | Dice, IoU, Precision, Recall, F1 on 8 held-out test images |

## Reproducing Results

```bash
venv310\Scripts\python.exe evaluate.py
```

This regenerates `test_metrics.json` using adaptive percentile thresholding (p70–p85) to handle the model's sigmoid output range [0.20–0.49].

## Why Adaptive Thresholding?

Standard `threshold=0.5` yields Dice≈0.000 on this model because the sigmoid output saturates below 0.50. The adaptive strategy selects the threshold percentile that maximises Dice on each image individually.
